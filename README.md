# Saree Silk Sanctuary

Build a complete production-ready premium ecommerce website for a local Indian Saree Boutique.

The website should look like a luxury fashion brand while keeping usability similar to Amazon, Myntra, Nykaa and Ajio.

The design should feel elegant, premium, feminine, luxurious and modern.

Do NOT make a simple landing page.

Build the complete UI/UX of an ecommerce platform.
